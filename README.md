# Taskati (Tasky)

تطبيق تنظيم مهام بـ Flutter — مشروع دورة Mastering Flutter.

## الشاشات (حسب تصميم فيجما Taskati)
- Splash: لوجو/أنيميشن Lottie ثم تنقّل تلقائي بـ `pushReplacement`
- إعداد البروفايل: صورة (كاميرا/معرض) + اسم، وبتنحفظ بـ Hive
- Home: ترحيب، شريط الأيام، قائمة المهام أو حالة "ما في مهام"، سحب لـ Complete / Delete
- Add Task: عنوان، وصف، تاريخ، وقت بداية ونهاية، لون
- Profile: تعديل الصورة والاسم، وتبديل الوضع الليلي

## التشغيل
```
flutter pub get
flutter run
```
